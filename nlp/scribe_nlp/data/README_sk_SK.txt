# Slovak Hunspell dictionary (LibreOffice)

Files `sk_SK.dic` and `sk_SK.aff` are from the LibreOffice dictionaries project
(https://github.com/LibreOffice/dictionaries/tree/master/sk_SK).

They are used offline by Scribe’s NLP spellcheck (`hunspell_dict.py`) without
native Hunspell bindings.

Typical licensing for LibreOffice language packs is GPL / LGPL / MPL — see the
upstream repository for the authoritative license text for this dictionary.
